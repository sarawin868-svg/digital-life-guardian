# 🛡️ Digital Life Guardian

> AI-Powered Personal Digital Safety & Document Monitoring System

Digital Life Guardian is a web-based personal digital safety assistant designed to help users monitor important documents, track expiry dates, identify potential risks, monitor security activity, and interact with an intelligent Guardian assistant.

---

## 🚀 Project Overview

Managing digital documents and personal security information manually can be difficult.

Digital Life Guardian provides a centralized dashboard where users can:

- 📄 Manage important documents
- ⏰ Track document expiry dates
- 🔴 Detect expired documents
- 🟠 Identify documents expiring soon
- 🛡️ Monitor security status
- 📊 Calculate a digital risk score
- 📈 Monitor security activity
- 🤖 Interact with Guardian AI
- 🧠 Get smart document priority suggestions
- 🌙 Switch between Light and Dark mode

---

## 🎯 Objectives

The main objectives of Digital Life Guardian are:

1. Create a centralized personal digital safety dashboard.
2. Monitor important document expiry dates.
3. Identify documents that require immediate attention.
4. Provide a simple security risk score.
5. Maintain activity logs for security monitoring.
6. Provide an AI-powered assistant for user queries.
7. Create a responsive and user-friendly interface.

---

## ✨ Key Features

### 📄 Document Management

Users can add documents along with their expiry dates.

The system automatically categorizes documents as:

- 🟢 Valid
- 🟠 Expiring Soon
- 🔴 Expired
- ⚪ No Expiry Date

---

### ⏰ Expiry Monitoring

The system calculates the remaining time for each document.

Examples:

- Expires today
- Expires tomorrow
- Expires in 10 days
- Expired 5 days ago

---

### 🛡️ Security Risk Score

The Guardian calculates a security score based on:

- Expired documents
- Documents expiring soon
- Security alerts
- Number of stored documents

Risk levels:

- 🟢 Safe
- 🟠 Attention Required
- 🔴 High Risk

---

### 📊 Security Activity Timeline

The system records important activities such as:

- Backend startup
- Security checks
- Guardian requests
- Document activities

The activity timeline provides a simple overview of recent system events.
